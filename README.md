# ATM Interface - Java

## Project Description
This is a simple ATM application developed using Java.

## Features
- Check account balance
- Deposit money
- Withdraw money
- Display updated balance
- Validate user input
- Prevent withdrawals when the balance is insufficient

## Technologies Used
- Java
- Scanner
- Switch statements
- Loops and conditional statements

## Initial Balance
The program starts with a sample balance of Rs. 1000.00.

## How to Run
1. Open the terminal in the project folder.
2. Compile using `javac ATMInterface.java`.
3. Run using `java ATMInterface`.
